KRISHNAJA WRITES — WEBSITE FILES

Open index.html in a web browser to view the site.
Keep all four files in the same folder:

index.html  — the page content and structure
style.css   — colours, typography, layout and photo styling
script.js   — journal articles, search, filters and navigation
profile.jpg — your profile photo

To edit the site, open these files in a text editor such as Visual Studio Code.
Changes to these downloaded files do not automatically update the hosted website.
